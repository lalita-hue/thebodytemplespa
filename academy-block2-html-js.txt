        <span class="eye">Why this matters</span>
        <h2 class="sh">Nothing moves until you open the pathway first</h2>
      </div>
      <div class="story">
        <div class="story-text rv">
          <p>Most therapists learn lymphatic drainage the way most drivers learn a shortcut: secondhand. A video, a weekend workshop, a coworker who picked it up somewhere. It sort of works &mdash; until a client asks a question you cannot answer, or you are not sure whether that swelling is normal healing or something you should be referring out today.</p>
          <p>Here is the thing about the lymphatic system: it has no pump of its own. Fluid only moves when you open the right pathway first. Push against a closed pathway and nothing drains, no matter how hard you work.</p>
          <div class="pull"><p>And it is not water you are moving.</p></div>
          <p>Almost everyone calls it water retention. It is not. It is <strong>fluid retention</strong>, and that fluid is a great deal more than water &mdash; plasma proteins too large for the blood capillaries to take back, cellular waste, bacteria, immune cells. That is why it sits there, and it is why moving it takes a sequence rather than pressure.</p>
          <p>The distinction is not trivia. Your clients research this before they book. Every time you say water retention to a client who has done their homework, you sound like someone who took a weekend course. Say <strong>fluid retention</strong>, explain what is actually in it and where you are sending it, and you sound like <strong>the expert they were looking for</strong>.</p>

(function(){
function init(){
  var root = document.getElementById('bta');
  if(!root) return;

  /* Reveal on scroll */
  var els = root.querySelectorAll('.rv');
  if('IntersectionObserver' in window){
    var io = new IntersectionObserver(function(entries){
      entries.forEach(function(e){
        if(e.isIntersecting){ e.target.classList.add('on'); io.unobserve(e.target); }
      });
    }, { threshold: 0.12, rootMargin: '0px 0px -40px 0px' });
    els.forEach(function(el){ io.observe(el); });
  } else {
    els.forEach(function(el){ el.classList.add('on'); });
  }

  /* FAQ accordion */
  root.querySelectorAll('.fq').forEach(function(btn){
    btn.addEventListener('click', function(){
      var item = btn.closest('.fitem');
      var isOpen = item.classList.contains('open');
      root.querySelectorAll('.fitem').forEach(function(i){ i.classList.remove('open'); });
      root.querySelectorAll('.fq').forEach(function(b){ b.setAttribute('aria-expanded','false'); });
      if(!isOpen){
        item.classList.add('open');
        btn.setAttribute('aria-expanded','true');
        if(window.dataLayer){ window.dataLayer.push({event:'faq_open', faq: btn.textContent.trim()}); }
      }
    });
  });

  /* Application modal — every Apply button opens the same form */
  var modal = root.querySelector('#btaModal');
  var lastTrigger = null;

  function openModal(trigger){
    if(!modal) return;
    lastTrigger = trigger || null;
    modal.hidden = false;
    document.body.style.overflow = 'hidden';
    var x = modal.querySelector('.modal__x');
    if(x) x.focus();
  }
  function closeModal(){
    if(!modal || modal.hidden) return;
    modal.hidden = true;
    document.body.style.overflow = '';
    if(lastTrigger && typeof lastTrigger.focus === 'function') lastTrigger.focus();
    lastTrigger = null;
  }

  root.querySelectorAll('.apply').forEach(function(b){
    b.addEventListener('click', function(){
      openModal(b);
      var where = b.getAttribute('data-cta');
      if(window.dataLayer){ window.dataLayer.push({event:'apply_click', location: where}); }
      if(typeof window.gtag === 'function'){ window.gtag('event','apply_click',{location: where}); }
    });
  });

  if(modal){
    modal.querySelectorAll('[data-close]').forEach(function(el){
      el.addEventListener('click', closeModal);
    });
    document.addEventListener('keydown', function(e){
      if(e.key === 'Escape' || e.key === 'Esc') closeModal();
    });
  }
}
  if(document.readyState === 'loading'){
    document.addEventListener('DOMContentLoaded', init);
  } else {
    init();
  }
})();
